# 「すり抜けさせたい」の一言が、敵を床に落とした話_2026-09-18

当たり判定シミュレーターの「検知のみ」ボタンが壊れていた。押すと敵が床を突き抜けて落ちていく。原因を追ったら、当たり判定というものが実は2つの別々の仕事をしていて、自分はその片方だけを止めたつもりで両方止めていた、という話だった。物理エンジンを使うなら早いうちに知っておいたほうがいい区別なので、書き残しておく。

## 作りたかったもの

このシミュレーターには「検知のみ」というボタンがある。押すと、プレイヤーが敵や置物をすり抜けるようになる。ただし触れたことは検知されて、相手が一瞬白く光る。「当たったことは分かるが、押し返さない」という状態を体験するためのボタンだ。

ゲームではこの設定をよく使う。アイテムの取得範囲、ダメージ判定、「この部屋に入ったらイベント発生」——どれも、重なったことは知りたいが、キャラクターを押し返してほしくはない。物理エンジンにはこれ専用の設定が用意されていて、一般に**センサー**と呼ばれる。コライダー（当たり判定用の形）に「お前はセンサーだ」と宣言すると、重なりの検出だけして、押し返しをやめてくれる。

なので私は、素直にそれを使った。ボタンが押されたら、敵と置物のコライダーを全部センサーに切り替える。実装は数行で終わったし、テストも書いた。「検知のみモードでプレイヤーが球判定のドーナツを通り抜けられること」「通り抜けたときにプレイヤーが光ること」。両方とも通った。

## しかし、実機で押したら敵が降ってきた

公開して、実際にスマホで触ってもらったら報告が来た。「検知のみにすると、すり抜けて落ちていく物体があります」。

再現テストを書いて回したら、2秒で16体中16体が床より下にいた。全滅である。

原因は、振り返れば当たり前だった。センサーにするというのは「**この形は、誰に対しても押し返さない**」という宣言であって、**相手がプレイヤーか床かを区別しない**。敵は床にも押し返されなくなったので、重力にしたがって落ちていった。そして場外に出たものを初期位置に戻す処理がそれを拾って空中に戻し、また落ちる。報告にあった「すり抜けて落ちていくものも、すり抜けず落ちていくものもある」という見え方は、この落下と復帰の繰り返しに、そもそも落ちない固定物が混ざっていたせいだった。

自分のテストがこれを見逃したのも、理由がはっきりしている。私は「プレイヤーが通り抜けられるか」しか確かめていなかった。**通り抜けてほしくない相手のことを、一度も確認していなかった。**

## 押し返しは、組み合わせごとに切れる

やりたかったのは「プレイヤーと敵の**組み合わせ**についてだけ、押し返しをやめる」ことだった。これはセンサーとは別の設定で指定する。

多くの物理エンジンには、**どの組とどの組が押し合うか**を指定する仕組みがある。0か1の並びで「自分はどのグループに属しているか」と「どのグループと押し合うか」を書き、両方が互いを指名している組み合わせだけ押し返しが実行される。Rapierではこれを solver group と呼ぶ。solver は「解く人」で、押し返しの計算を担当する部分のことだ。

重要なのは、この仕組みで押し返しを切っても、**接触の検出とイベントは生きたまま**だということ。だから「すり抜けるけど光る」がちゃんと成立する。プレイヤーと置物の組だけを外した結果、敵は床の上に立ったまま、敵同士は押し合ったまま、プレイヤーだけがすり抜けるようになった。落下は16体中0体になった。

整理すると、切りたいものによって使う道具が違う。この形は誰に対しても押し返さない、ならセンサー。この組み合わせだけ押し返さないが検出はしたい、なら押し返しのグループ指定。この組み合わせはそもそも検出すらしたくない（計算を軽くしたい）、なら検出のグループ指定。3つ目まであるとは、正直この件を追うまで意識していなかった。

## 自分への持ち帰り

当たり判定は「重なりを検出する仕事」と「重なりを解消する仕事」の2つでできていて、止めたいのがどちらなのかを毎回はっきりさせる。曖昧なまま一番手近な設定を使うと、今回のように**止めるつもりのなかった相手との関係まで一緒に切れる**。

テストの書き方も改める。何かを「通れるようにする」変更を入れたら、**通れてほしくない相手が今も通れないこと**を必ず同じ回で確認する。片側だけのテストは、壊れたことを教えてくれない。今回の再発防止として「検知のみモードで2秒放置しても敵が1体も落ちない」を検査項目に足した。

そして、この教材を他のゲームの下敷きにするときは、センサーを使う場面が来たら一度立ち止まる。アイテムの取得範囲のように、その物体が本当に誰に対しても実体を持たなくていいならセンサーでいい。キャラクター同士だけすり抜けさせたいなら、それはグループ指定の仕事だ。
